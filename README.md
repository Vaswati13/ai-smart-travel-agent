# 🌍 VoyageAI - Smart AI Travel Agent

![VoyageAI Banner](https://github.com/user-attachments/assets/your-image-link)

## ✈️ Plan Smarter. Travel Better. Explore More.

VoyageAI is an AI-powered travel assistant that helps users create personalized travel experiences with intelligent trip planning, destination insights, weather updates, hotel recommendations, local services, and an interactive AI travel companion.

Built with modern web technologies, VoyageAI combines Generative AI, real-time APIs, and location-based services to make travel planning faster, smarter, and more personalized.
